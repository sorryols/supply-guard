# Журнал змін

## 1.1.0

Перехід до правила рішення без ваг і ймовірностей:

- Індикатори бінарні (спрацював / не спрацював), ваги та модель «шумного АБО» вилучено.
- Правило рішення: критичний індикатор (К1–К5) — блокування (код 2); спрацював хоча б один звичайний
  індикатор або серед авторів є новий учасник — **на розгляд розробника** (код 1); інакше — допуск (код 0).
- Динамічний аналіз запускається, якщо спрацювало щонайменше `rules.dast_min_indicators` (типово 2) індикатори.
- Ступінь довіри до авторів змін позначено `Da`; індикатор A3 спрацьовує, якщо `Da < trust.low_threshold` (типово 0,5).
- Рівень небезпеки: критичний (c = 1), високий (n ≥ `rules.high_level_indicators`), середній (n = 1–2), низький (n = 0).
- Параметр `deps.use_malicious_db` для експериментів без бази шкідливих бібліотек (К4).
- Звіт: поля `triggered_count`, `author_trust`; поля `anomaly_probability`, `update_trust` вилучено.
- Термінологія повідомлень: «бібліотека» замість «пакет».
- Експериментальний стенд: показники блокування та виявлення, розбиття за типами зразків, частота індикаторів;
  `experiments/build_dataset.py` готує вибірку з DataDog malicious-software-packages-dataset.

## 1.0.1

Виправлення за результатами експерименту на реальних бібліотеках PyPI:

- **A5:** тег версії шукається також серед усіх тегів репозиторію з порівнянням нормалізованих версій
  (`2024.08.30` = `2024.8.30`, `release_2024.2`) — усунено хибні попередження для certifi, pytz.
- **S6:** файли, згенеровані системою збирання (`_version.py`, `_dist_ver.py` від setuptools-scm, hatch-vcs),
  не вважаються підозрілими — усунено хибне попередження для tqdm.
- **B2:** внутрішні програми компілятора C (`cc1`, `collect2`, `gcc-12`, `ld.bfd` тощо) не вважаються
  запуском сторонніх програм — усунено хибне блокування markupsafe.
- **Мережа:** повторні спроби запитів при тимчасових збоях (з'єднання, HTTP 429/5xx).
- **Експериментальний стенд:** текст помилки аналізу зберігається в results.csv.
- Версія засобу входить до ключа кешу результатів.
- Додано 5 блокових тестів (усього 77).
